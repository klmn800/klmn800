## What's here

- **doc-review-pipeline** — Batch document reviewer that pulls .docx attachments out of emails (.msg/.eml), runs
them through Claude, and writes structured analysis to a tracker. Built to replace a manual review queue.
- **query-db-direct** — SQLite exploration tool with schema discovery and dynamic query suggestion. Designed so AI
agents can use it as readily as humans can.
- **media-wall** — Local masonry-grid media viewer with autoplay, tagging, and filtering. A self-hosted
alternative to cloud galleries.
- **archive-cracker** — Utility for recovering personal media from locked .rar archives.

More in progress.
